# Joe vs Mac

```
git clone https://github.com/dmvjs/gameboy-game-maker.git
cd gameboy-game-maker
npm i
npm start
```

The first time takes a few minutes. Then the editor opens with the game loaded: press **▶ Test** to play.
You also get `joe-vs-mac.gb`, which plays in any Game Boy emulator.

Controls: arrows move, **X** right punch, **Z** left punch, **Up + punch** to the face, **Enter** star punch.

You need Python 3.9 or newer (Macs have it; on Windows get it from python.org) and Node.js (nodejs.org).
No Node? Skip `npm i` / `npm start` and double-click **Start.command** (Mac) or **Start.bat** (Windows).
